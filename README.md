# 🛒 Online Electronics Shopping Website

This is a full-stack e-commerce web application built with Django as a learning project by a beginner student exploring the Django framework.  
The platform allows users to browse electronic products, filter items, add them to a shopping cart, place orders, and complete real-time payments securely using Razorpay.

---

## ✨ Features

✅ **User Registration & Login**  
- New users can register an account and securely log in to manage their shopping activities.

✅ **User Account & Profile**  
- Users can update their account information and shipping address for smooth order delivery.

✅ **Product Browsing & Filtering**  
- Browse a wide range of electronic items.
- Use multiple filters to sort products by price, color, or category.
- Sort products by relevance, price (low to high / high to low), or newest arrivals.

✅ **Shopping Cart**  
- Add products to the cart directly from the product listing or product detail page.
- View cart contents at any time.
- Update item quantities or remove items before placing an order.

✅ **Order Placement & Payment**  
- Place secure orders for the items in the cart.
- Integrated Razorpay for real-time online payments.
- After successful payment, users receive confirmation and can track their orders.
